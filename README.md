# AB Talks AI Curator (Team Boomers)

Autonomous AI Curator Agent that continuously discovers tech trends, validates them with memory retention (Breeth), synthesizes thoughtful posts (Claude), and maintains an autonomous publishing cycle.

## Project Structure
- `backend/`: Express.js API server and autonomous agent brain.
- `docs/`: Database schema and documentation.
- `workflows/`: Scheduled workflow definitions (n8n).
- `PROMPTS.md`: AI prompt interaction history log.
